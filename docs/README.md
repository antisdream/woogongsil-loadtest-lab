## 문서화 기준

- 원문을 그대로 복제하지 않고 테스트 목적, 조건, 결과, 개선 방향 중심으로 정리한다.
- 민감 정보와 원시 로그는 저장소에 포함하지 않는다.
- 테스트 결과는 운영 배포 판단의 보조 자료로 사용한다.
